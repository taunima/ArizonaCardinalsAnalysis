# Arizona Cardinals Analysis

For this project I decided that I would analyze the AZ Cardinals best and worst seasons across it's entire franchise history with their performance as well in those seasons.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install Quarto and Python 3.14.1
2. Install required Python packages for the polars and lets plot. pip3 install polars (lets-plot)
3. Ensure that the csv file is in the same folder as the qmd file.

Instructions for using the software:

1. You must run each cell starting from top to bottom in order for the program to run properly.
2. Once you click "Run Cell" it will bring up a interactive cell to the side to show you that it has ran successfully or not.
3. Once you have confirmed it as ran you can now run the next cell and continue to do so until it is all ran. Or you could run the whole by clicking preview at the top to the right where you would normally run the program.
